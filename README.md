# Should I insure it?

A small calculator that goes with the LSE Actuarial Society newsletter article *Are You Covered? An Actuary’s Insurance Checklist for Students*.

- Everything is in `index.html`: no build step, no dependencies.
- To edit: change `index.html`, commit, and push. Vercel redeploys automatically.
- Sources: every figure on the page has a link. They live in the `S = { ... }` object near the top of the script.
- Last checked: 23 November 2026.

This is a teaching tool, not personal insurance or financial advice.
